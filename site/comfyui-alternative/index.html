Kokon / Simple ComfyUI alternative

A simple ComfyUI alternative for editing photos

ComfyUI gives you every knob. Kokon gives you the result. If you want to edit photos with AI on your own computer without building workflows, this page explains what Kokon decides for you, and when ComfyUI is still the right tool. Updated October 21, 2026.

ComfyUI is great, if you want to build

ComfyUI is the most flexible way to run image models locally: a node graph where you wire up every step. That flexibility is the point, and it's also why so many people bounce off it. To edit one photo you need Python or the portable build, the right custom nodes, four or five model files in the right folders, a workflow, and settings that fit your VRAM.

Kokon is built on a different idea: most people want the edited photo, not the pipeline. So we make the technical choices, test them, and ship them as one app.

Already have ComfyUI files?

Kokon's setup can use model files you already have on disk, for example in a ComfyUI models folder, instead of downloading them again. Your own Qwen-Image 2.1 LoRAs work too (beta): Kokon makes its own prepared copy and never changes your file.

When to stay with ComfyUI

  • You want custom pipelines: ControlNet chains, video, many models in one graph.
  • You want to tune samplers, schedulers and steps yourself.
  • You use models Kokon doesn't ship. Kokon is opinionated on purpose: one tested model, not a model zoo.

Many people use both: ComfyUI for experiments, Kokon for quick edits and for friends who will never open a node graph.

Is it the same engine?

No. Kokon runs the model through stable-diffusion.cpp, a native C++ engine (Kokon ships its own tested build), so there is no Python at all. It uses CUDA on NVIDIA, Vulkan on AMD and Intel, and Metal on Macs.

Questions

Is there a simpler alternative to ComfyUI?

For editing and creating photos, yes: Kokon is a free desktop app with no nodes and no Python. It downloads the model and picks the settings for your graphics card; you describe the change.

Can Kokon use my ComfyUI model files?

Yes, if they are the same model files Kokon uses. Setup can point at files you already have on disk instead of downloading them again.

Can I change the sampler, steps or CFG in Kokon?

Not next to the prompt: Kokon uses tested defaults so you never have to. If you need full control over the pipeline, ComfyUI is the better tool.

Does Kokon support LoRAs?

Yes, in beta: your own Qwen-Image 2.1 LoRA files, loaded in Settings and turned on per project, up to three at a time.
