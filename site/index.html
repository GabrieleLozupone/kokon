How it works

Run Qwen-Image 2.1 locally in three steps.

No Python environment, no ComfyUI workflows, no model files to hunt down. Read the full guide.

1

Download the installer

A native app for Windows 10/11 (about 55 MB), macOS on Apple Silicon or Linux (.deb and .rpm, about 75 MB). On Windows it installs for your user, no admin rights needed.

2

Let it set up the model

Kokon detects your GPU (NVIDIA, AMD, Intel or Apple Silicon), picks the right preset and downloads Qwen-Image 2.1 Turbo, with resume and SHA-256 checks.

3

Describe the change

Drop a photo, write what you want and press Enter. Or paint an area first, and only that area changes.

FAQ

Questions.

Is it really free?

Yes. Kokon is open source under the GNU AGPL-3.0 license. No account, no credits, no subscription, no daily limit. It uses your own GPU, so there is nothing to pay for. The images are for non-commercial use, because of the model's license (see below).

Is Kokon a local alternative to Nano Banana or ChatGPT image editing?

For editing photos with a sentence, yes: "remove the people", "make it a snowy night", "change the sign to say…". The difference is where it runs. Kokon runs on your own GPU, so your photos are never uploaded and there are no limits or subscriptions. Cloud models run on data-center GPUs and can be faster or stronger on some edits; Kokon uses Qwen-Image 2.1, which leads the open-weights image-editing rankings. More in Kokon vs Nano Banana.

Can I choose a different model?

Kokon makes that choice for you, on purpose. We test the open image models and ship the best one as the default, tuned for your graphics card, so you never have to compare checkpoints, samplers or settings. Today that is Qwen-Image 2.1 Turbo. When a better open model comes out and wins our tests, an update brings it. If you already have the same model files on disk (for example from ComfyUI), setup can use them instead of downloading them again, and you can add your own LoRAs.

How do I run Qwen-Image 2.1 locally without ComfyUI?

Install Kokon and let its setup download the model. Kokon runs Qwen-Image 2.1 through stable-diffusion.cpp, a native engine, so there is no Python, no ComfyUI and no workflow to build. The step-by-step guide is at kokon.app/qwen-image-2-1-local.

Which model does it use?

Qwen-Image 2.1 Turbo, the official 8-step version of Qwen's image model, which both creates and edits images and leads the open-weights image-editing rankings.

Does it work on AMD or Intel GPUs?

Yes, in beta, through the Vulkan engine on Windows with 12 GB of VRAM or more. On NVIDIA it uses CUDA; on Apple Silicon Macs it uses Metal.

My GPU has 8 GB. Will it work?

Yes, in beta. Kokon makes images at about 1 megapixel on 8 GB cards; users report it works on an RTX 3060 Ti and an RTX 5050 Laptop (1 to 2 minutes per edit). 16 GB of system RAM is recommended. On a Mac, 16 GB of unified memory works but slowly; 32 GB is recommended.

Can Claude Code or Cursor generate images with it?

Yes. Kokon ships an MCP server: register it once and any MCP client can create, edit, inpaint, expand and upscale images on your GPU, for free and without an API key.

Is it an alternative to Photoshop Generative Fill?

For many edits, yes: paint an area and describe what should be there, or remove, replace and add objects. It runs offline and costs nothing, but it is an AI editor, not a full layer-based image editor.

Can I use the images commercially?

Not with the default model. The app is open source (AGPL-3.0), but Qwen-Image 2.1 is released under the Qwen Research License: research and evaluation only, no commercial use without a license from the Qwen team. The default upscaler (Superscale-SP) allows commercial use; the optional UltraSharp upscaler is non-commercial (CC BY-NC-SA 4.0).

Windows says the app is unrecognized. Is it safe?

The beta installer is not code-signed yet, so SmartScreen warns about it. Click "More info" and then "Run anyway". The code is public and every download the app makes is checked against a pinned hash.

macOS says Kokon cannot be opened. What do I do?

The beta is not notarized by Apple yet, so macOS blocks it the first time:

  1. Open Kokon. macOS says “Kokon” Not Opened: click Done (not Move to Trash).
  2. Open System Settings → Privacy & Security and scroll down to Security. Next to “Kokon” was blocked to protect your Mac, click Open Anyway and confirm with your password or Touch ID.
  3. Open Kokon again and click Open. You only do this once; in-app updates don't trigger it again.

If macOS instead only says The application “Kokon” can't be opened, with just an OK button, and Privacy & Security shows no Open Anyway: open Terminal, run xattr -dr com.apple.quarantine /Applications/Kokon.app, then open Kokon as usual. This removes the “downloaded from the internet” flag from Kokon only.

How do I write good prompts for Qwen-Image 2.1?

Describe the scene, not just the subject: who, doing what, where, in what light. Never write “no X” (it adds X), put text in quotes, and for edits name the exact thing to change. The prompt guide shows each rule with a vague and a clear prompt side by side.

Does it run on Linux?

Yes, in beta, on x86-64: a .deb for Ubuntu, Debian and Mint and an .rpm for Fedora, from the latest release. Install it with sudo apt install ./Kokon_<version>_amd64.deb or sudo dnf install ./Kokon-<version>-1.x86_64.rpm. NVIDIA cards need the proprietary driver; AMD and Intel cards use Vulkan. A headless server with the interface in your browser, then Docker, come next.

What is Prompt+?

An optional helper next to the prompt box. Write a short idea in any language and Prompt+ writes a detailed English prompt from it (looking at your photo for edits), then makes the image; the result keeps both prompts. It runs on Qwen3-VL, the text encoder Qwen-Image 2.1 already loads, inside Kokon's own build of stable-diffusion.cpp, so there is no second model to download. It adds about 2 seconds per image on an RTX 5070 Ti.

Can I use LoRAs?

Yes, in beta: your own LoRA files made for Qwen-Image 2.1 (.safetensors). Load them in Settings → LoRA and turn them on for each project with the LoRA button next to the prompt, up to 3 at a time. LoRAs for older Qwen-Image versions don't work with 2.1. Tested on Windows so far; there is no LoRA catalog yet, because the popular LoRAs we tested didn't improve on what Turbo does with a good prompt.

Does it work offline?

Yes. After setup has downloaded the models, everything runs offline.
